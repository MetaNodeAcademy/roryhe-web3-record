### 私有链搭建

1.拉取 go-ethereum 源码
```
git clone https://github.com/ethereum/go-ethereum.git
cd go-ethereum
git checkout v1.10.26
```

2.处理/下载依赖
```
go mod download/go mod tidy
```
3.编译Geth
```
make geth
//验证
./build/bin/geth version
```
![[验证.png]]

```
//启动服务
./build/bin/geth --dev --http
```
![[启动.png]]
![[ScreenShot_2025-12-17_174435_568.png]]

4.通过控制台验证功能：
eth.blockNumber
miner.start()
![[功能验证.png]]
#### 重新调整启动参数:
1.创建数据目录
 ```
 ./build/bin/geth account new --datadir ./private-chain
 ```
2.创建对应的genesis.json
3.初始化链数据
```
./build/bin/geth init --datadir ./private-chain ./genesis.json
```
4.启动Geth节点
```
 ./build/bin/geth \
  --datadir ./private-chain \
  --networkid 1337 \
  --http \
  --http.api eth,net,web3,personal \
  --allow-insecure-unlock \
  --unlock 0x295eB2E01f0080ba3962F187347186c05440BdD6 \
  --password pwd.txt \
  --mine \
  --nodiscover \
  console
```
5.通过控制台验证功能
```
1.eth.blockNumber
2.让指定账户作为 Clique signer 出块并获得区块奖励（mine.start()）
```

### 智能合约部署(通过Remix部署)
给指定账户转入ETH：
```
1.修改gemesos.json
"alloc": {  
  "295eb2e01f0080ba3962f187347186c05440bdd6": {  
    "balance": "0x8AC7230489E80000"  
  }  
}
2.删除旧链，重新初始化链
rm -rf ./private-chain

./build/bin/geth init --datadir ./private-chain ./genesis.json
```
重新启动Geth ：
```
 ./build/bin/geth \
  --datadir ./private-chain \
  --networkid 1337 \
  --http \
  --http.addr 127.0.0.1 \
  --http.port 8545 \
  --http.api eth,net,web3,personal \
  --http.corsdomain "*" \
  --http.vhosts "*" \
  --allow-insecure-unlock \
  --unlock 0x295eB2E01f0080ba3962F187347186c05440BdD6 \
  --password pwd.txt \
  --nodiscover \
  console



```

通过Remix部署
在geth控制台执行 miner.start()
Remix部署成功后，miner.stop()
